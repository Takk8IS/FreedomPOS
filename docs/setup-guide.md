# hiPOS Setup Guide

## System Requirements

- Windows 10 or later
- 4GB RAM minimum
- 1024x768 minimum screen resolution
- Compatible hardware:
    - Receipt printers (58mm/80mm)
    - Cash drawers
    - Barcode scanners
